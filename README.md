# Study Studio updates

This public repository serves signed updates for the Study Studio Mac app. It contains app packages and update metadata only. Personal classes, uploaded study materials, and account credentials are never included.

[Download the latest Mac app](https://github.com/ifracius-cyber/StudyStudio-Updates/raw/main/downloads/Study-Studio-3.20.zip)

After installing version 3.20 once, Study Studio checks this repository for later signed updates automatically. You can also choose **Study Studio → Check for Updates…** in the menu bar.
